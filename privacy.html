Privacy Policy — GYB Backup

Last updated: 2026-09-22

GYB Backup is a personal tool for an individual to back up their own Gmail account. It requests read-only Gmail access (gmail.readonly) to read Gmail messages and settings, and permission to confirm the email address of the Google Account. It does not send, delete, or modify Gmail data.

Gmail messages may contain personal information about other people, including senders’ and recipients’ names, email addresses, and message contents. GYB Backup stores this information only as part of the backed-up messages. It does not extract such information for separate use or use it for any other purpose.

Backups are stored only on the user's own local computer drive and home NAS managed by the user. They are not stored on cloud servers.

Backups are retained until the user deletes them.

To stop future data retrieval, remove GYB Backup's access in the Google Account “Third-party apps and services” settings. To delete existing backups, delete the backup folders from every storage location (the computer drive and the NAS).

The user should keep backups only on devices used by the user and must not disclose authentication credentials.

GYB Backup does not sell data, use it for advertising, or provide it to other parties. It complies with the Google API Services User Data Policy, including the Limited Use requirements.

For inquiries, please use GitHub Issues.

GYB Backup は、個人が自分自身の Gmail アカウントをバックアップするためのツールです。読み取り専用の Gmail 権限（gmail.readonly）により Gmail のメールと設定を読み取り、Google アカウントのメールアドレスを確認します。メールの送信、削除、変更は行いません。

Gmail のメールには、送信者・宛先の氏名、メールアドレス、本文など、他人に関する個人情報が含まれることがあります。GYB Backup は、これらの情報をメールの一部としてそのままバックアップに保存しますが、情報を抜き出して別の用途に利用することはありません。

バックアップは、利用者本人が管理する PC のローカルドライブおよび家庭内 NAS にのみ保存されます。クラウドのサーバーには保存しません。

バックアップは、利用者本人が削除するまで保存されます。

以後のデータ取得を停止するには、Google アカウントの「サードパーティ製のアプリとサービス」から GYB Backup のアクセスを外してください。保存済みのバックアップを削除するには、すべての保存先（PC のドライブと NAS）のバックアップフォルダを削除してください。

バックアップは利用者本人だけが使用する機器に保存し、認証情報を公開しないでください。

GYB Backup は、データの販売、広告への利用、第三者への提供を行いません。Google API Services User Data Policy（Limited Use を含む）に従います。

お問い合わせは GitHub Issues をご利用ください。
