GYB Backup

About this app

GYB Backup is a personal tool operated by the GitHub user aandk1024. It is used only by the operator to back up the operator’s own Gmail, with read-only access, to the operator’s own computer and home NAS.

This app is not offered to the public and is not intended for use by third parties.

Privacy Policy

このアプリについて

GYB Backup は、GitHub ユーザー aandk1024 が運営する個人用ツールです。運営者本人の Gmail を、読み取り専用で、本人の PC と家庭内 NAS にバックアップするためだけに使います。

一般には提供しておらず、第三者による利用を想定していません。
